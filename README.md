PDF COMPRESSOR

A simple and efficient web-based PDF Compressor built using Python. This tool allows users to upload PDF files and reduce their size while maintaining quality.

FEATURES
Upload PDF files easily
Compress PDF size quickly
Reduce file size without major quality loss
Simple web interface
Docker support for deployment

TECH STACK
Backend: Python (Flask)
Frontend: HTML, CSS
Deployment: Docker
PROJECT STRUCTURE

pdf-compressor/

static/ → CSS, JS, assets
templates/ → HTML templates
app.py → Main Flask app
requirements.txt → Dependencies
Dockerfile → Docker config
start.sh → Startup script
README.txt → Documentation
